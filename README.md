# 💰 Smart Expense Tracker

A full-stack personal finance management web application built with **Python Flask and PostgreSQL**.

It helps users manage income and expenses, set monthly budgets, analyze spending, and generate financial reports.

## ✨ Features

* 🔐 User registration and login
* 💰 Income management
* 💸 Expense management
* ✏️ Edit and delete expenses
* 🔎 Search expenses
* 📊 Expense analytics and charts
* 🎯 Monthly budget management
* ⚠️ Budget warning and progress tracking
* 💵 Income, expense and balance calculation
* 📅 Monthly expense tracking
* 📈 Expense statistics
* 📄 CSV and PDF reports
* 👤 Profile and password management
* 📱 Responsive user interface

## ⚙️ Installation

Clone the repository:

```bash
git clone https://github.com/YOUR_USERNAME/smart-expense-tracker.git
cd smart-expense-tracker
```

Create and activate a virtual environment:

```bash
python -m venv venv
venv\Scripts\activate
```

Install dependencies:

```bash
pip install -r requirements.txt
```

## 🗄️ Database Setup

Create a PostgreSQL database:

```sql
CREATE DATABASE smart_expense_db;
```

Configure your PostgreSQL connection details in the application.

**Do not upload your PostgreSQL password or secret keys to GitHub.**

## ▶️ Run the Application

```bash
python app.py
```

Open:

```text
http://127.0.0.1:5000
```
